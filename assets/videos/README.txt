HERO VIDEO INSTRUCTIONS
========================

To replace the video for the hero editorial card:

Option 1 (Direct File Replacement):
- Place your video file in this folder and name it:
  hero-video.mp4
  (Path: wp-content/themes/tcc-theme/assets/videos/hero-video.mp4)

Option 2 (WordPress Admin / Media Library):
- Go to WordPress Admin -> Appearance -> Customize -> Hero Section
- Upload or paste your video URL in the "Hero Portrait Video" field
- Click "Publish"
